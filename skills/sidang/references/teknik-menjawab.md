# Teknik Menjawab

## Format tiga kalimat

Setiap jawaban maksimal 20 detik, tiga kalimat:

```
K1  Jawaban langsung     — ya/tidak/angkanya
K2  Alasan atau bukti    — angka, tabel, rujukan
K3  Batas atau lanjutan  — cakupan, atau apa yang belum terjawab
```

Contoh:

```
P: "Kenapa sampelnya hanya 4 orang?"
J: [K1] "Karena ini studi kasus pada satu puskesmas yang seluruh petugas gizinya
       berjumlah empat orang — jadi ini sensus, bukan sampel."
   [K2] "Dengan demikian seluruh populasi di lokasi itu tercakup."
   [K3] "Konsekuensinya, temuan tidak bisa digeneralisasi ke puskesmas lain,
       dan itu saya nyatakan di bagian keterbatasan."
```

Yang dilanggar kalau lebih dari tiga kalimat: penguji kehilangan alur dan akan memotong.

---

## Empat pola jawaban

### 1. Pola ANGKA (untuk pertanyaan hasil)

```
"Nilainya [angka] pada [tabel]. Artinya [satu kalimat]. Namun [batas]."
```

### 2. Pola PILIHAN (untuk pertanyaan "kenapa X, bukan Y")

```
"Saya memilih X karena [karakteristik data/konteks]. Y tidak dipakai karena
[alasan teknis konkret]. Kalau Y dipaksakan, [konsekuensi]."
```

### 3. Pola AKUI (untuk pertanyaan yang tidak bisa dijawab)

```
"Saya belum memeriksa itu. Yang bisa saya katakan dari data yang ada adalah
[batas pengetahuan]. Untuk menjawabnya perlu [data/analisis tambahan]."
```

Mengarang lebih merusak daripada mengaku. Penguji sering sudah tahu jawabannya — mereka
menguji kejujuran.

### 4. Pola BATAS (untuk klaim berlebihan)

```
"Temuan ini berlaku pada [cakupan spesifik]. Di luar itu saya tidak bisa
menyimpulkan karena [alasan]. Itu sebabnya saya menuliskannya sebagai
keterbatasan."
```

## Menangani jebakan

### "Kalau saya bilang metode Anda salah?"

Jangan membela diri. Bedakan dua hal:

- **Menjelaskan pilihan** = sah, dan menunjukkan penguasaan.
- **Mempertahankan harga diri** = merusak suasana, revisi diperketat.

```
✅  "Yang saya pahami, uji ini dipilih karena skala datanya ordinal dan
     kelompoknya dua. Kalau ada pertimbangan lain yang saya lewatkan,
     bagian mana yang perlu saya perbaiki?"
```

### "Menurut Anda, kenapa hasilnya begitu?"

Jebakan mengarang. Jawab dengan batas:

```
✅  "Dari data yang ada, saya bisa menyimpulkan ada hubungan. Untuk menjelaskan
     sebabnya, saya hanya bisa mengajukan dugaan yang didukung [bukti]. Di luar
     itu perlu data tambahan."
```

### "Ini benar Anda yang kerjakan?"

Jangan tersinggung, jangan menyangkal panjang. Buktikan dengan detail:

```
✅  "Ya. Misalnya di Tabel 4.3, koefisien 0,412 itu dari regresi sederhana
     dengan satu prediktor; R² 0,34 karena variabel lain tidak masuk model.
     Saya bisa jelaskan langkah perhitungannya kalau perlu."
```

Detail teknis membuktikan penguasaan. Penyangkalan tidak.

### "Teori Anda tidak cocok dengan hasil."

```
✅  "Betul, hasil tidak mendukung teori itu pada konteks ini. Perbedaannya
     karena [mekanisme yang didukung data]. Justru itu yang saya bahas di
     subbab 4.6."
```

### "Coba jelaskan ulang."

Bisa berarti lo tidak jelas, bisa berarti uji mental. Ulangi lebih pendek:

```
✅  satu kalimat inti + satu contoh konkret + satu angka
```

Jangan mengulang dengan kalimat yang sama persis.

### "Anda baca naskah Anda sendiri?"

```
✅  "Ya." + sebut satu bagian spesifik yang relevan dengan pertanyaan sebelumnya.
```

## Mengelola panik

### Sebelum menjawab: tulis pertanyaannya

Saat penguji bertanya, ambil pulpen dan **tulis 2–3 kata kunci** pertanyaannya. Efeknya:

1. Memberi 3–5 detik untuk berpikir tanpa terlihat diam.
2. Mencegah menjawab pertanyaan yang salah.
3. Menyisakan catatan untuk revisi.

### Kalau pertanyaan berlapis

```
✅  "Jadi yang ditanyakan ada dua hal: A dan B. Saya jawab A dulu."
```

### Kalau benar-benar blank

```
✅  "Boleh saya lihat catatan saya sebentar?"
```

Itu normal. Yang tidak normal adalah diam 15 detik lalu mengarang.

### Kalau penguji memotong

Berhenti. Jangan melanjutkan kalimat. Jawab pertanyaan barunya. Memaksa menyelesaikan
kalimat yang dipotong terlihat tidak mendengarkan.

### Kalau dua penguji bertentangan

```
✅  "Saya memahami ada dua pandangan. Yang saya pakai dalam naskah adalah [X]
     karena [alasan]. Kalau disarankan [Y], saya siap memperbaiki di revisi."
```

Jangan memihak salah satu. Ambil posisi metodologis, bukan posisi orang.

## Suara dan tubuh

| Hal | Yang benar | Yang salah |
|---|---|---|
| Kecepatan | 130–150 kata/menit | >180 (gugup) atau <100 (tidak siap) |
| Jeda | berhenti 1 detik antar gagasan | "ee", "gitu", "kan", "apa ya" |
| Mata | bergantian ke tiap penguji 3–5 detik | menatap satu orang atau ke layar terus |
| Tangan | di meja atau memegang pulpen | di saku, memainkan kabel, gelisah |
| Posisi | berdiri tegak, tidak bersandar | bersandar ke meja, bergoyang |
| Volume | cukup terdengar di baris belakang | terlalu pelan saat gugup |

### Latihan mengurangi filler

1. Rekam jawaban 8 pertanyaan wajib.
2. Hitung filler ("ee", "gitu", "kan", "apa ya").
3. Ulangi, target: kurang dari 3 filler per jawaban.

Filler muncul karena pikiran mendahului mulut. Solusinya bukan "jangan bilang ee", tapi
**berhenti diam** saat butuh waktu.

### Tanda lo kelebihan waktu

- Melewati slide hasil tanpa membahas angkanya.
- Membaca teks slide.
- Menjelaskan teori panjang di awal.
- Menjawab "nanti saya jelaskan di slide berikutnya" lebih dari sekali.

## Penutup

Jangan akhiri dengan "sekian, terima kasih" saja. Akhiri dengan tiga butir:

```
"Sebagai penutup: pertama, kualitas data berada pada kategori sedang dengan
kelemahan pada konsistensi. Kedua, ketepatan pelaporan 62%, di bawah target
95%. Ketiga, kualitas data menyumbang 34% variasi ketepatan pelaporan.
Terima kasih."
```

20 detik, dan penguji keluar ruangan dengan tiga angka itu di kepala — bukan dengan
kesan bahwa lo tidak bisa meringkas.
