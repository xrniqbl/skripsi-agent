# Menolak dengan Alasan

## Kapan boleh menolak

Menolak catatan pembimbing adalah hak lo — tapi hanya dengan **argumen metodologis**, bukan
selera. Tiga kondisi yang sah:

1. **Catatan bertentangan dengan kaidah metodologi.** Contoh: diminta menyimpulkan
   kausalitas dari data korelasional.
2. **Catatan tidak bisa dijalankan dengan data yang ada.** Contoh: diminta uji longitudinal
   padahal data hanya satu titik waktu.
3. **Catatan bertentangan dengan catatan sebelumnya**, dan lo perlu memilih satu.

Yang **bukan** alasan penolakan:

```
❌  "sudah dari awal begitu"
❌  "kata kakak tingkat begitu"
❌  "tidak sempat"
❌  "malas ngulang analisis"
❌  "menurut saya sudah benar"
```

## Format argumen

Empat bagian, maksimal satu paragraf:

```
1. Catatan yang ditolak (kutip persis)
2. Alasan metodologis (bukan selera)
3. Rujukan ke bagian naskah yang mendukung alasan itu
4. Tawaran alternatif (kalau ada)
```

Contoh utuh:

```markdown
### R-04 — Uji beda dihapus

- **Catatan**: "kayaknya uji beda nggak perlu, cukup deskriptif aja" (bimbingan 2026-10-14)
- **Klarifikasi**: ditanyakan 2026-10-16; pembimbing menjawab "maksudnya kalau cuma
  mau tahu gambaran, tidak perlu uji beda"
- **Keputusan**: **ditolak sebagian** — uji beda dipertahankan untuk rumusan 3,
  dihapus untuk rumusan 1 dan 2
- **Alasan**: rumusan 3 (hal 3) menanyakan *perbedaan* ketepatan pelaporan antar
  kelompok kualitas data, sehingga uji deskriptif tidak dapat menjawabnya. Rumusan 1
  dan 2 hanya menanyakan gambaran, jadi cukup deskriptif — dan bagian itu sudah
  diubah sesuai catatan.
- **Rujukan naskah**: rumusan 3 hal 3; desain analisis hal 28; Tabel 4.3 hal 52
- **Status**: ditolak-dengan-alasan
- **Tanggal**: 2026-10-17
```

## Cara menyampaikan ke pembimbing

Jangan menyampaikan penolakan di depan kelas atau lewat pesan panjang. Format yang aman:

```
Selamat pagi Pak/Bu. Terkait catatan tentang uji beda, saya sudah pelajari.

Rumusan masalah ketiga menanyakan perbedaan antar kelompok, jadi menurut
pemahaman saya uji beda masih diperlukan untuk menjawabnya — kalau hanya
deskriptif, rumusan 3 tidak terjawab.

Tapi untuk rumusan 1 dan 2 saya sudah ubah jadi deskriptif sesuai catatan.

Apakah pemahaman saya benar, atau ada pertimbangan lain yang saya lewatkan?
```

Tiga hal yang membuat ini bekerja:

1. **"menurut pemahaman saya"** — membuka ruang koreksi, tidak menantang.
2. **"untuk rumusan 1 dan 2 sudah saya ubah"** — menunjukkan lo mengerjakan, bukan menolak
   semuanya.
3. **"apakah pemahaman saya benar"** — memberi pembimbing jalan untuk setuju tanpa merasa
   dikoreksi.

## Kalau pembimbing tetap menolak argumen lo

Ada tiga kemungkinan:

### 1. Lo salah — terima dan kerjakan

Tanda: pembimbing menjelaskan alasan yang belum lo pertimbangkan.

```
✅  "Baik Pak, saya kurang mempertimbangkan itu. Saya perbaiki."
```

### 2. Lo benar, tapi ini bukan pertarungan yang layak

Tanda: perbedaannya kecil, dan mengejar akan menghabiskan waktu bimbingan.

```
✅  kerjakan sesuai permintaan, catat di keterbatasan penelitian
```

Ini bukan menyerah — ini memilih menggunakan energi untuk hal yang lebih berdampak.

### 3. Lo benar dan ini material (menyangkut keabsahan hasil)

Tanda: permintaan akan membuat naskah salah secara metodologis, dan penguji sidang akan
menangkapnya.

Tindakan: **jangan berdebat, tapi jangan ikuti juga.** Minta tertulis, lalu konsultasi ke
pembimbing kedua atau kaprodi:

```
✅  "Baik Pak. Boleh saya minta catatan ini tertulis, supaya saya bisa
     konsultasikan juga ke pembimbing dua sebelum saya ubah?"
```

Ini sopan, dan memindahkan keputusan ke jalur yang tepat. Yang **tidak boleh**: mengerjakan
sesuatu yang lo tahu salah, lalu menyalahkan pembimbing saat sidang.

## Kalau tidak ada jawaban

Pembimbing kadang tidak membalas. Setelah 3–5 hari:

```
Selamat pagi Pak/Bu. Saya ingin menindaklanjuti pertanyaan saya tanggal ...
tentang [X]. Saya sudah mengerjakan bagian lain sambil menunggu. Kalau
memungkinkan, saya ingin konfirmasi arah untuk bagian ini supaya tidak
salah arah.
```

Lalu **lanjutkan bagian lain**. Jangan menunggu satu butir klarifikasi sambil berhenti
total — itu penyebab utama skripsi tertunda berbulan-bulan.

## Aturan penutup

- Penolakan **selalu** punya catatan tertulis di `01_revisi.md`, bahkan kalau akhirnya
  lo mengalah. Kalau nanti ditanya "kenapa tidak dikerjakan?", ada jejaknya.
- Jangan pernah menolak tanpa pernah bertanya. "Saya tidak setuju" bukan klarifikasi.
- Jangan menyimpan penolakan di kepala. Yang tidak tertulis akan diingat berbeda oleh
  dua orang.
