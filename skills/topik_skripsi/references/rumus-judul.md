# Rumus Judul Skripsi

## Judul adalah kontrak, bukan hiasan

Judul yang baik menjanjikan tiga hal sekaligus, dan pembimbing akan menagih ketiganya di
sidang:

1. **Apa yang diteliti** (objek)
2. **Apa yang dilakukan** (tindakan/metode)
3. **Di mana / pada siapa** (lokus)

Kalau salah satu hilang, judul itu belum siap — dan biasanya bab III-nya juga belum siap.

---

## Tiga unsur wajib

| Unsur | Isi | Contoh benar | Contoh salah |
|---|---|---|---|
| **Objek** | variabel, sistem, proses, atau fenomena | "kualitas data rekap gizi" | "sistem informasi" (terlalu luas) |
| **Tindakan** | verba penelitian | "Pengaruh", "Analisis", "Rancang Bangun", "Hubungan" | "Kajian tentang" (kabur) |
| **Lokus** | instansi + wilayah, atau populasi spesifik | "Puskesmas X, Kabupaten Y" | "di Indonesia" |

Urutan lazim: **Tindakan → Objek → Lokus**.

```
Pengaruh kualitas data rekap terhadap ketepatan pelaporan gizi
di Puskesmas X Kabupaten Y
└tindakan┘└──── objek ────────────┘└────── lokus ──────────┘
```

## Pola per bidang

Pilih pola yang sesuai program studi — pembimbing menilai "kesesuaian bidang" dari sini.

### Manajemen / Akuntansi / Ekonomi

```
Pengaruh X terhadap Y pada Z
Pengaruh X dan Y terhadap Z dengan W sebagai variabel moderasi
Analisis faktor-faktor yang memengaruhi Y pada Z
```

Contoh: *Pengaruh kualitas data dan beban kerja terhadap ketepatan pelaporan keuangan pada
Kantor Pelayanan Pajak X*

### Sistem Informasi / Teknik Informatika

```
Rancang Bangun A untuk B
Analisis dan Perancangan A berbasis B pada C
Pengembangan A dengan Metode B pada C
Evaluasi A menggunakan B pada C
Implementasi B untuk A pada C
```

Contoh: *Rancang Bangun Dashboard Rekap Gizi Berbasis Web untuk Puskesmas X*

> Hati-hati: "Analisis dan Perancangan" mengandung **dua verba**. Banyak pedoman kampus
> melarang. Pilih satu, atau ubah menjadi "Rancang Bangun".

### Teknik (sipil, industri, mesin, elektro)

```
Perancangan A dengan Metode B
Optimasi A menggunakan B pada C
Analisis A terhadap B
Perbandingan Metode A dan B pada C
```

Contoh: *Optimasi Rute Distribusi Menggunakan Algoritma Genetika pada PT X*

### Kesehatan / Keperawatan / Gizi

```
Hubungan A dengan B pada C
Pengaruh A terhadap B pada C
Gambaran A pada C
Efektivitas A terhadap B pada C
```

Contoh: *Hubungan Beban Kerja dengan Kepatuhan Pelaporan pada Petugas Gizi Puskesmas X*

Catatan: desain korelasional memakai **"Hubungan"**, bukan "Pengaruh". Memakai "Pengaruh"
untuk desain korelasional adalah kesalahan yang paling sering ditanyakan di sidang.

### Hukum

```
Tinjauan Yuridis terhadap A dalam B
Analisis Hukum A menurut B
Perlindungan Hukum terhadap A dalam B
Penerapan Asas A dalam B
```

### Pendidikan

```
Pengaruh Model A terhadap B Siswa Kelas X
Pengembangan Media A untuk B
Peningkatan A melalui B
```

### Sosial / Politik / Komunikasi

```
Analisis A dalam B
Representasi A dalam B
Strategi A dalam B
```

### Pertanian / Peternakan / Perikanan

```
Pengaruh A terhadap B pada C
Uji A terhadap B
Analisis Kelayakan A pada B
```

## Aturan panjang dan bentuk

| Aturan | Nilai | Alasan |
|---|---|---|
| Jumlah kata | **15–25** (cek pedoman kampus) | di bawah 15 terlalu umum; di atas 25 sulit dibaca |
| Verba utama | **1** saja | dua verba = dua pekerjaan = dua skripsi |
| Singkatan | hanya yang baku (SPK, UML, IoT) | "SIMRS" harus dieja bila belum lazim |
| Kata mubazir | buang "suatu", "di sini", "yang mana", " terhadap suatu" | |
| Lokus | instansi + wilayah | "di Indonesia" tidak bisa diteliti dalam satu semester |
| Klaim hasil | **dilarang** | "yang meningkatkan kinerja" mengasumsikan jawaban |
| Huruf | Kapital di awal kata penting, bukan ALL CAPS | |

## Kesalahan yang paling sering

### 1. Judul mengandung dua penelitian

> ❌ *Analisis dan Perancangan Sistem Informasi Serta Pengaruhnya terhadap Kinerja*

Tiga pekerjaan sekaligus: analisis, perancangan, pengaruh. Pilih satu.

### 2. Judul tanpa lokus

> ❌ *Pengaruh Kualitas Data terhadap Kinerja Pelaporan*

Tidak bisa diteliti — pelaporan siapa, di mana, periode apa.

### 3. Lokus terlalu luas

> ❌ *... di Indonesia* / *... pada UMKM di Jawa Timur*

Satu orang, satu semester. Perkecil ke satu instansi atau satu wilayah administratif.

### 4. Klaim di judul

> ❌ *Rancang Bangun Sistem yang Meningkatkan Efisiensi Pelaporan*

Kalau belum diuji, "meningkatkan" adalah asumsi. Buang.

### 5. Objek abstrak tanpa batas

> ❌ *Analisis Kualitas Sistem Informasi*

Kualitas menurut apa? Sistem apa? Di mana?

### 6. Metode disembunyikan padahal jadi kontribusi

> ❌ *Sistem Pendukung Keputusan Pemilihan Karyawan*

Kalau kontribusinya adalah metode (SAW, TOPSIS, AHP), sebutkan: *... dengan Metode TOPSIS*.

### 7. Campur bahasa tanpa aturan

> ❌ *Analisis User Experience Aplikasi Mobile Banking*

Istilah asing boleh, tapi harus konsisten dan miring di naskah. Banyak kampus meminta
padanan Indonesia bila ada ("pengalaman pengguna").

### 8. Judul yang tidak cocok dengan metode

> ❌ *Pengaruh X terhadap Y* — tapi desainnya studi kasus kualitatif

"Pengaruh" menuntut pengujian statistik. Untuk kualitatif pakai "Analisis", "Makna",
"Strategi", atau "Praktik".

## Uji judul

```bash
python3 scripts/judul_check.py 04_kandidat_judul.md --maks-kata 25 --bidang sistem_informasi
```

Yang diperiksa skrip:

| Pemeriksaan | Tingkat | Tindakan |
|---|---|---|
| jumlah kata di luar rentang | galat | potong atau tambah lokus |
| lebih dari satu verba penelitian | galat | pilih satu |
| tanpa lokus (tidak ada "pada/di" + nama instansi/wilayah) | galat | tambahkan |
| lokus terlalu luas ("Indonesia", "nasional") | galat | perkecil |
| singkatan tidak baku | peringatan | eja atau daftarkan di daftar singkatan |
| kata klaim ("meningkatkan", "mengoptimalkan" sebagai hasil) | peringatan | hapus |
| kata mubazir ("suatu", "yang mana") | peringatan | hapus |
| verba tidak cocok dengan pola bidang | peringatan | sesuaikan |
| duplikasi antar kandidat (≥80% kata sama) | peringatan | pilih satu arah |

Skrip **tidak** menilai apakah topiknya bagus — itu tugas FINER. Ia hanya menilai bentuk.

## Format berkas kandidat judul

```markdown
## K1 — Rekap gizi

**Arah:** kuantitatif korelasional

1. Pengaruh Kualitas Data Rekap terhadap Ketepatan Pelaporan Gizi di Puskesmas X Kabupaten Y
2. Hubungan Ketepatan Pelaporan dengan Kualitas Data Gizi pada Petugas Puskesmas X
3. Analisis Faktor Penyebab Ketidaksesuaian Data Rekap Gizi di Puskesmas X

## K2 — ...
```

Aturan: **3–6 varian per kandidat**, dengan arah metode yang sama. Varian boleh berbeda
sudut (pengaruh / hubungan / faktor), tapi tidak boleh berbeda pekerjaan.

## Checklist sebelum diserahkan ke pembimbing

- [ ] 15–25 kata
- [ ] satu verba penelitian
- [ ] objek spesifik dan terbatas
- [ ] lokus instansi + wilayah
- [ ] cocok dengan desain (pengaruh↔kuantitatif, makna↔kualitatif)
- [ ] tanpa klaim hasil
- [ ] tanpa singkatan tidak baku
- [ ] tidak identik dengan judul skripsi yang sudah ada di repositori kampus
- [ ] lolos `judul_check.py` tanpa galat
- [ ] bisa diucapkan dalam satu tarikan napas

Poin terakhir bukan bercanda. Judul yang tidak bisa diucapkan akan salah disebut di
undangan sidang dan di berita acara.
