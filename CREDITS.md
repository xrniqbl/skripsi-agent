# Kredit dan Lisensi

Bundel Skripsi Agent menyatukan skill-skill open-source berikut. Seluruh hak cipta tetap
pada pembuat masing-masing; berkas lisensi asli di dalam setiap folder skill adalah
yang berlaku. Repo ini adalah agregasi untuk kemudahan install, bukan klaim kepemilikan.

Catatan lisensi:

- Komponen berlisensi **CC BY-NC 4.0** (suite ARS) hanya boleh digunakan untuk tujuan
  non-komersial, dengan atribusi kepada pembuat aslinya.
- Komponen berlisensi **MIT** boleh digunakan, disalin, dan dimodifikasi dengan tetap
  menyertakan pemberitahuan lisensinya.
- Satu berkas gambar referensi (`deep_research/references/workflow.png`) tidak ikut
  terbawa dalam unggahan awal repo ini karena batasan format unggah; seluruh teks dan
  alur skill tersebut lengkap tanpanya.
